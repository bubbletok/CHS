# 프로젝트 작성 가이드

이 폴더의 각 `.md` 파일 하나가 프로젝트 하나다. 파일명 앞 숫자(01, 02…)가 화면에 나오는 순서를 정하니, 순서를 바꾸고 싶으면 숫자만 바꾸면 된다.

## 위쪽 (frontmatter, `---` 사이)

```yaml
id: my-project          # 고유 id, 영문/숫자/하이픈
engine: unity            # unity 또는 unreal
status: video            # playable / video / wip / company
title: 프로젝트 이름
tab: 탭에 표시될 짧은 이름
subtitle: 한 줄 부제
pitch: 강조 인용구 (선택)
badge: 배지 텍스트 (선택, 예: 2024 G-STAR)
meta:
  기간: 2024.01 ~ 2024.06
  멤버: 5명
  역할: 클라이언트 개발
  기술 스택: Unity / C#
stack:
  - Unity
  - C#
poster: /Projects/폴더명/포스터.png   # 없으면 생략, 자동으로 색 플레이스홀더 카드가 된다
shots:
  - /Projects/폴더명/스샷1.jpg
links: {}                # 또는 play: https://... 처럼
```

`status`가 `company`면 카드 그리드에서 "COMPANY" 뱃지로 따로 묶여 보인다.

## 아래쪽 (본문, 그냥 글로 쓰면 됨)

`##` 제목을 아래 4가지 중 하나로 쓰면 자동으로 해당 항목에 들어간다. 그 외 제목은 무시된다.

- `## 요약` → 상세 페이지 상단 인용구
- `## 역할 — 뭐뭐` → "역할" 섹션 (제목 그대로 노출)
- `## 문제점: 뭐뭐` → "생겼던 문제점들"에 아코디언 항목 하나 추가 (여러 개 가능, 기본은 접혀 있고 클릭하면 펼쳐진다).
  본문 맨 앞에 연달아 `![](/Projects/폴더명/스샷.png)`를 쓰면(여러 장 가능) 펼쳤을 때 그 문제점 전용 스크린샷으로 보여준다 (선택)
- `## 수상` → 목록 (각 줄 `- ` 로 시작)

예시는 다른 `.md` 파일들 참고. 이 형식에 없는 필드가 필요하면 코드(`lib/loadProjects.js`)를 손봐야 한다.
